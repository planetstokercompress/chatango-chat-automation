## 🤖 The Ultimate Chatango Companion

**Chatango Chat Automation** is a powerful, lightweight script designed to take the manual labor out of managing your Chatango rooms. 

Whether you run a massive anime community, a gaming hub, or a niche support room, keeping the chat active and clean is a full-time job. This automation tool changes the game. It acts as your personal digital bouncer and entertainer.

Built with modern JavaScript, it hooks directly into the Chatango API. You can set up custom auto-responses, ban spam bots instantly, welcome new users with dynamic messages, and even create mini-games for your community. It runs silently in the background, ensuring your chat remains a safe and engaging space without you having to stare at the screen 24/7.

> 💡 **Why use this automation?** Because your time is better spent building your community, not deleting spam links. Let the script handle the grunt work while you focus on growth.

## 🚀 Quick Start

> **Three steps. Under two minutes. No installation required.**

### 1️⃣ Clone the repository

```bash
git clone https://github.com/yourname/chatango-automation.git
cd chatango-automation
```

### 2️⃣ Configure your credentials
Rename `.env.example` to `.env` and add your Chatango bot username and password.

### 3️⃣ Run the bot

```bash
node index.js --room "your_room_name"
```

## ⚙️ How It Works

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---|
| 🕷️ **Connector** | Maintains WebSocket connection to Chatango | `Node.js` |
| 🧠 **Command Parser** | Processes incoming messages for triggers | `Regex` |
| 🛡️ **Moderation Engine** | Applies rules and kicks users | Custom logic |
| 💾 **Database** | Stores rules, logs, and user stats | `SQLite` |

</div>

The script uses reverse-engineered Chatango WebSocket protocols to send and receive messages. It's designed to be lightweight, meaning you can run it on a Raspberry Pi or a free-tier cloud server.

## ❓ Frequently Asked Questions

<details>
<summary><b>Will Chatango ban my account?</b></summary>

Automation technically violates Chatango's Terms of Service. However, this script uses human-like delays and respects rate limits to avoid detection. Still, it is highly recommended to use a **dedicated bot account**, not your personal main account.
</details>

<details>
<summary><b>Does it support multiple rooms?</b></summary>

Yes. You can pass an array of room names in the config file, and the bot will connect to all of them simultaneously.
</details>

<details>
<summary><b>Can I host this for free?</b></summary>

Yes. Because it's a lightweight Node.js app, you can host it on free tiers like Railway, Render, or even run it locally in the background.
</details>

<details>
<summary><b>How do I add custom commands?</b></summary>

Check the `modules/` folder. You can easily create a new JavaScript file to handle a custom trigger (e.g., `!discord` to post an invite link).
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository. Include the command you typed and the error output from the console.
</details>
